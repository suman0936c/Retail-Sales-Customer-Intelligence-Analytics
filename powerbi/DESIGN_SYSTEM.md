# Retail Intelligence Premium — Design System

## Visual language

- **Canvas:** `#F8FAFC` light neutral background.
- **Surfaces:** white, borderless visual cards with subtle soft shadow.
- **Headings:** deep navy `#0F172A`, Segoe UI Semibold.
- **Primary metric/data accent:** teal `#0F8B8D`.
- **Secondary series:** blue `#2563EB`.
- **Attention/risk:** muted orange `#F59E0B`; reserve red `#E11D48` for adverse performance only.
- **Supporting text/grid:** slate greys.

## Layout rules

- 1920×1080 16:9 canvas.
- 60px page margin and 40px vertical separation between analytical rows.
- Top KPI strip, then main analytical panels, then detailed analysis.
- White space and aligned edges take precedence over adding more visuals.

## Formatting rules

- GBP measures use £ formats; percentages use `0.0%`.
- Charts use a restrained teal/blue palette and readable 10–16px typography.
- Visual headers are hidden to reduce UI noise.
- Tables use a navy header, slate text, and light gridlines.
